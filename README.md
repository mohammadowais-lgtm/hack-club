# 🐍 SNAKE: DIE. GET STRONGER.

*A terminal roguelike where every death makes you stronger.*

What if dying wasn't the end, but the beginning of your next evolution?

**SNAKE: DIE. GET STRONGER.** is a terminal-based Snake game built in Java for Linux and macOS. It takes the classic Snake experience and adds permanent progression: collect food, earn evolution XP, die, unlock mutations, and return stronger.

## 🎮 Features

- **Classic Snake gameplay** — Navigate the board, collect food, and avoid collisions.
- **Permanent progression** — Earn evolution XP as you play and retain your progress between runs.
- **Evolution Lab** — Spend XP to unlock permanent mutations.
- **Longer Launch** — Begin each run with a longer snake.
- **Second Chance** — Survive one collision per run.
- **Quick Learner** — Earn additional XP from food.
- **Star Map** — Increase the score earned from food.
- **Persistent save system** — Your XP, deaths, best score, and unlocked mutations are saved locally.
- **Terminal aesthetic** — Colored ASCII graphics and keyboard controls.

## 🛠️ Built With

- Java
- Terminal-based rendering
- ANSI escape sequences
- Java file I/O for persistent saves

## 🚀 How to Run

**Requirements:** Java JDK 11 or newer and a Linux/macOS terminal.

1. Clone the repository:

   ```bash
   git clone https://github.com/mohammadowais-lgtm/hack-club.git
   cd hack-club
   ```

2. Compile the game:

   ```bash
   javac Snake.java
   ```

3. Run it:

   ```bash
   java Snake
   ```

## 🎯 Controls

| Key | Action |
|---|---|
| Arrow keys | Move the snake |
| `R` / `Space` | Start or retry |
| `P` | Pause |
| `M` | Open the Evolution Lab |
| `Q` | Quit |

## 💡 The Idea

Every run teaches you something. Every death gives you another chance to evolve. The goal isn't just to survive longer—it's to become stronger with every attempt.

**Die. Learn. Evolve. Repeat.**
